# 치매돌봄 리빙랩 공개 전 개인정보·윤리 점검

- 점검일: 2026-07-24
- 대상: `https://dementia-livinglab.soilabcoop.kr/`
- 운영자: 협동조합 소이랩
- 목적: 페이스북 등 외부 링크를 통한 일반 방문 전에 개인 단위 자료의 노출과 무단 변경 가능성을 차단

## 확인된 주요 위험

개선 전 공개 도메인에서는 인증 없이 다음 자료에 접근할 수 있었다.

- 기관 연락처와 주소
- 익명 대상자 코드, 치매 단계, 참여 동의 여부와 중도 이탈 정보
- 워크시트 작성자명, 대상자 코드, 워크시트 원문과 검토자 정보
- 예산 지급 대상·증빙 관련 필드
- 참가자·기관·대상자 CSV 내보내기
- 안전기록, 워크숍 원자료와 사진 메타데이터 API
- 관리자 로그인 없이 가능한 일부 생성·수정 요청

치매 단계는 건강정보에 해당하므로 일반 개인정보보다 엄격하게 다뤄야 한다. 익명 코드도 다른 정보와 결합해 개인을 알아볼 수 있다면 개인정보 또는 가명정보로 취급해야 한다.

## 적용한 보호 조치

- 참가자, 워크숍, 예산, 안전·윤리, 가이드북, 사진, 역할, CSV API를 관리자 세션 전용으로 전환
- 공개 워크시트 응답에서 작성자명, 그룹명, 대상자 코드, 원문, 검토자 정보와 토큰 제거
- 공개 대시보드는 치매 단계별 집계만 제공하고 대상자 행 단위 자료를 제거
- 기관별 대상자 수가 5명 미만인 경우 정확한 숫자를 공개하지 않는 소수집단 억제 적용
- 예산 지급 대상, 체크리스트 완료자·증빙, 워크숍 장소·퍼실리테이터 등 내부 필드 제거
- 관리자 비밀번호 원문을 쿠키에 저장하지 않고, 8시간 만료 서명 세션으로 교체
- 로그인 시도 제한, AI 보고서 생성 API 관리자 전용화
- 관리자 민감자료 조회·수정·다운로드를 세션·IP의 비가역 지문과 함께 감사 로그로 기록
- 신규 워크시트 토큰을 144비트 난수로 강화하고 기존 짧은 토큰 무효화
- 공개 워크시트 작성 시 실명·대상자 코드·직접 건강정보 입력 금지 안내 및 확인 기록 추가
- 사진 파일을 관리자 인증 프록시로 제공하고 신규 업로드는 비공개 Blob 저장소를 요구
- CSP, 클릭재킹 방지, `nosniff`, `no-referrer`, 권한 정책, HSTS와 API `no-store` 헤더 적용
- 개인정보 처리 안내 페이지 추가
- 공개 검토가 끝날 때까지 검색엔진 색인 차단

## 공개 전에 운영자가 확인할 사항

1. 배포 후 비로그인 상태에서 민감 API가 `401`을 반환하는지 다시 확인한다.
2. 현재 관리자 비밀번호를 16자 이상의 고유한 값으로 교체하고 공유 메신저에 남기지 않는다.
3. 기존의 짧은 워크시트 링크는 새 링크로 재발급한다.
4. 실제 참여 동의서에 개인정보와 민감정보를 구분한 처리 목적·항목·보유기간·제3자 제공·위탁 내용을 반영한다.
5. 얼굴 사진은 촬영 동의와 공개 활용 동의를 구분하고, 비공개 Blob 저장소가 연결되기 전에는 업로드하지 않는다.
6. Vercel, Supabase, Anthropic 계약·리전·보유기간을 실제 계약 내용과 대조해 개인정보 처리 안내를 확정한다.
7. 사업 종료와 동의 철회 요청에 대응할 삭제 담당자와 처리 절차를 지정한다.
8. 관리자 계정을 여러 사람이 함께 사용해야 한다면 단일 비밀번호 방식 대신 개인별 계정과 다중요소 인증으로 전환한다.
